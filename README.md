# 大闸蟹蟹卡预约日期监控助手（本地版）

这是一个运行在 Windows 电脑上的浏览器辅助程序。GitHub 只保存代码；真正的监控在你自己的电脑浏览器中运行，不依赖 GitHub Actions 定时任务。

## 功能

- 打开蟹卡兑换页面：`https://hmgz.7ckd.cc/type33?mercid=454`
- 使用本机独立浏览器目录保存登录会话。
- 你本人在浏览器中输入卡号和密码、选择商品、填写收货信息。
- 进入第 3 步“填写配送信息”并看到“发货日期”下拉框后，程序按设定间隔检查日期选项。
- 检测到疑似可预约日期时，尝试选中该日期并弹窗提醒。
- 如果出现验证码、安全验证、访问频率限制或 HTTP 403/429，程序停止，不会绕过验证或继续高频请求。
- **不会自动点击最终订单确认按钮**。你需要检查商品、日期和收货信息，再由你本人完成最终提交。

## Windows 安装

1. 安装 Node.js LTS：<https://nodejs.org/zh-cn>。安装时保持默认选项，确保 npm 和 PATH 选项没有被取消。
2. 在 GitHub 仓库点击 **Code → Download ZIP**。
3. 在 Windows 文件资源管理器中，对下载的 ZIP 右键选择 **全部解压**。不要直接在 ZIP 压缩包内运行 BAT。
4. 打开解压后的文件夹，确认能看到 `package.json`、`install.bat` 和 `start.bat`。
5. 双击 `install.bat`。窗口会保持打开；安装输出会保存到 `install-log.txt`。
6. 安装完成后双击 `start.bat` 启动。
7. 在弹出的浏览器中手动完成蟹卡验证、商品选择和收货信息填写，进入第 3 步“填写配送信息”。
8. 确认页面显示“发货日期”下拉框后，回到黑色命令窗口按回车开始监控。
9. 发现疑似可预约日期后，程序会尝试选中并提醒你。请核对页面后，手动完成订单审核和最终提交。

## 如果 BAT 窗口一闪而过

- 请确认先解压 ZIP，再运行 BAT。
- 在解压文件夹地址栏输入 `cmd` 并按回车，然后输入 `install.bat` 或 `start.bat` 执行。这样即使脚本报错，命令提示符也不会自动关闭。
- 把窗口中完整的错误文字发给我。安装失败时也可以把 `install-log.txt` 发给我。
- 确认 Node.js 安装后重新打开一个新的命令窗口，再运行 BAT。

## 修改检查间隔

打开 `config.json`，修改 `checkIntervalSeconds`。默认 60 秒，程序限制在 60–300 秒之间。不要尝试缩短间隔来绕过网站的限流或预约规则。

## 安全

- **不要把蟹卡卡号、密码、短信验证码发给任何人，也不要提交到 GitHub。**
- 卡号和密码由你本人在浏览器页面中输入；程序不会读取密码输入框。
- 浏览器 Cookie 和登录状态保存在本机 `.browser-profile` 文件夹。不要分享此文件夹。
- 收货姓名、电话和地址仅在当前浏览器页面中由你填写；程序不会把它们写入配置文件或日志。
- `.gitignore` 已排除 `.browser-profile`、`node_modules` 和日志文件。
- 建议把 GitHub 仓库设置为 **Private（私有）**。

## 重要限制

目前无法稳定访问兑换网站进行真实环境测试，因此本程序尚未验证网站实际 HTML 结构、日期下拉框动态更新方式，以及登录状态在刷新后是否保持。第一版根据页面可见的日期下拉框识别“疑似可预约”日期；如果网站使用其他控件或页面结构，可能无法识别，需要根据你提供的脱敏截图继续适配。

日期下拉框出现可选项不等于库存已锁定，也不代表兑换成功。最终结果以网站订单审核和订单状态为准。本工具不破解验证码、不绕过登录、不伪造接口请求、不规避网站限流，也不保证预约成功。

## 故障排查

- **无法识别发货日期**：确认已经在第 3 步，并且页面上确实显示日期下拉框；发送不包含个人信息的截图以便适配。
- **刷新后退出登录**：在浏览器中重新登录并回到第 3 步，再重新启动程序。
- **出现验证码或访问限制**：请遵循网站提示，必要时联系蟹卡发行方。
- **安装失败**：检查 `install-log.txt`，确认 Node.js 和 npm 已安装，并检查网络后重新运行 `install.bat`。
